# Al-Aqsa University Website

A responsive university website developed as an individual project for the Web 1 course.

The project was built using vanilla HTML, CSS, and JavaScript to practice fundamental front-end development concepts and create an interactive university-style website.

## Features

- Responsive university landing page
- University information section
- Faculties section
- News section
- Events section
- Contact section
- Embedded Google Maps
- Scroll animations
- Interactive user interface
- Arabic RTL layout

## Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
- AOS (Animate On Scroll)
- SweetAlert2

## Project Type

Academic Project — Web 1 Course
